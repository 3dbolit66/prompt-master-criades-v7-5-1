# Prompt Master Criades V7.5.1

Actualització incremental sobre la V7.5.

## Novetats principals
- Retrat d'estudi amb enquadrament independent i opcions Headshot, primer pla, bust, mig cos, tres quarts i cos sencer.
- Headshots frontal i 3/4, i noves poses de retrat.
- Body Morphology ampliat: alçada, pes, constitució, forma, pit, cintura, malucs, espatlles, braços, proporció de cames i tors, postura i presència corporal.
- Locks de proporció cap/cos i consistència multi-vista.
- Maquillatge ampliat: intensitat, estil, acabat de pell, ulls, llavis i galtes, amb realism lock.
- Character sheet: noms més clars per a Fitxa base del personatge i Fitxa d'outfit concret.
- Color vestuari convertit en desplegable de combinacions i paletes.
- Nou perfil de vestuari Patrona / mestressa d'alt estatus.
- Opcions Old money, Quiet luxury, New money refinat, New money visible i New money contemporani.
- Controls de sofisticació, estatus, silueta, teixit, accessoris i formalitat per a patrones.
- Nou perfil Minyona · dia lliure / roba modesta amb roba econòmica, segona mà, barata però ben combinada, etc.
- Conserva les funcions i locks de la V7.5, inclòs Gris paloma / Dove grey.
